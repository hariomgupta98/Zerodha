# Zerodha Clone (MERN Stack)

A Zerodha-inspired stock trading platform built using the MERN Stack. This project is currently under development, and the goal is to recreate the core features of Zerodha with a modern and responsive interface.

## Current Progress

* Responsive Landing Page
* React Frontend Setup
* Express.js Backend Setup
* MongoDB Atlas Connected
* API Integration Started

## Coming Soon

* User Login & Signup (JWT Authentication)
* Dashboard
* Portfolio & Holdings
* Orders & Positions
* Watchlist
* Profile Management

## Tech Stack

**Frontend**

* React.js
* Bootstrap
* React Router
* Axios

**Backend**

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose

## Installation

### Clone the repository

```bash
git clone https://github.com/hariomgupta98/Zerodha.git
cd Zerodha
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm start
```
